## 🏗️ YÊU CẦU KỸ THUẬT

**Kiến trúc:**
- Modular, plugin-based cho multi-vendor (thêm vendor mới = thêm driver, không sửa core)
- Layer rõ ràng: Collector → Storage → Analyzer → Notifier → API/UI
- Concurrent execution (ThreadPoolExecutor hoặc asyncio)
- Retry + exponential backoff khi kết nối thất bại
- Structured logging (JSON), config-driven (YAML/JSON/CSV/DB)

**Sao lưu:**
- SSH qua Netmiko + tùy chọn RESTCONF/NETCONF
- Command khác nhau theo vendor (show running-config vs display current-configuration)
- Xử lý paging, terminal length, timeout, prompt
- Lưu file: {vendor}/{hostname}/{YYYY-MM-DD_HH-MM-SS}.cfg
- Tùy chọn commit vào Git repo (mỗi backup = 1 commit)
- Checksum SHA256 để phát hiện trùng lặp

**Phát hiện thay đổi:**
- Unified diff với backup trước
- Phân loại theo section (interface, ACL, routing)
- Đánh dấu thay đổi nghiêm trọng (ACL, route, user, crypto)
- Lưu change log vào DB (SQLite/PostgreSQL)

**Khôi phục an toàn:**
- Dry-run trước
- Backup cấu hình hiện tại trước khi restore
- Xác nhận 2 bước cho production
- Auto-rollback nếu health check thất bại

**Giám sát hiệu năng:**
- System: CPU 5s/1m/5m, memory, uptime, temperature
- Interface: status, error counters, CRC, drops, bandwidth
- Protocol: BGP/OSPF neighbor state, route count
- Reachability: ICMP, TCP port check, latency
- Lưu time-series (InfluxDB/Prometheus/SQLite), cảnh báo threshold

**Bảo mật & Vận hành:**
- Credential trong Vault/.env/encrypted store, KHÔNG hard-code
- RBAC: viewer/operator/admin, audit log cho mọi restore
- Docker + docker-compose, APScheduler hoặc Celery Beat
- Unit test + integration test (mock Netmiko)
